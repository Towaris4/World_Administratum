# Лабораторная работа № 1

**Mundus Administratum / World Administratum**  
**Тема:** волонтёр улучшает местное государство научными работами и наблюдениями.

## 1. Цель работы

Волонтёр улучшает один местный орган государства. Средство улучшения — не просьба «стать лучше», а:

- наблюдения (повторяемые факты);
- научная работа по этим наблюдениям;
- отправка исследования в нужное место;
- из работы — одно конкретное изменение процедуры.

## 2. Кто и что

| | |
|---|---|
| Кто улучшает | волонтёр, гражданин **Administrator planetarius** |
| Чем улучшает | научные работы и наблюдения |
| Что улучшает | местное государство (один орган, одна услуга за раз) |

## 3. Закон, без которого работа не засчитывается

Волонтёр знает название и латинское имя. Это закон.

- Название: **World Administratum**
- На латинском: **Mundus Administratum**
- Гражданин: **Administrator planetarius**

## 4. Задачи волонтёра

1. Выбрать один местный орган и одну услугу.
2. Наблюдать, как услуга идёт сейчас. Записать факты.
3. Повторить наблюдение не меньше трёх раз.
4. Написать научную работу: что видно, что мешает человеку, что изменить.
5. Отправить исследование в нужное место (орган или адрес, где этот баг или это право разбирают).
6. Сформулировать улучшение, которое местный орган может ввести, и как проверить, что стало лучше.
7. Защита права — через арбитра, просто отстояв, после отправки.

## 5. Материалы

- `nablyudeniya.csv` — журнал наблюдений
- `nauchnye_raboty/` — тексты научных работ
- `otpravka.csv` — куда отправлено исследование
- `volunteers.csv` — кто какой орган улучшает какой работой

Только публичный контур: сайт, регламент, очередь, приёмная, свой опыт получения услуги. Секреты, взлом, давление на сотрудников — вне работы.

## 6. Ход работы

### Шаг 1. Наблюдение

Одно наблюдение = одна дата, одна услуга, один канал (окно / сайт / телефон).

Писать в `nablyudeniya.csv`:

| Дата | Орган | Услуга | Канал | Ожидание | Ответ | Лишнее требование | Что увидел |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

Без трёх наблюдений научная работа не пишется: нет фактов.

### Шаг 2. Научная работа

Файл: `nauchnye_raboty/<фамилия_или_инициалы>_<услуга>.md`  
Образец: `nauchnye_raboty/_obrazec.md`

В работе обязательно:

- название **World Administratum** и латинское **Mundus Administratum**;
- ссылки на строки наблюдений;
- вывод: какое улучшение местного государства следует из фактов.

### Шаг 3. Отправка в нужное место

Нужное место — орган или адрес, где этот сбой или это право реально разбирают. Не «всем» и не «в интернет вообще».

Писать в `otpravka.csv`: дата, файл работы, куда, канал (окно / почта / сайт / приёмная).

Пока строки нет — исследование не отправлено. Без отправки арбитр отстоять не может: стоять не на чем.

### Шаг 4. Улучшение

Из научной работы — одно изменение:

> Местный орган делает ________, потому что наблюдения показали ________.  
> Признак, что стало лучше: ________ (число или срок, не лозунг).

Это и есть вклад волонтёра в местное государство. Право, если его задели, защищают через арбитра: отправить и отстоять.
